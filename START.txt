💡 KEY CONCEPTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ROUTING: Displaying different components based on URL path

COMPONENTS:
  🔷 BrowserRouter    - Enables routing in the app
  🔷 Link             - Navigation without page reload
  🔷 Routes           - Container for all routes
  🔷 Route            - Maps URL path to component

PATTERNS:
  • Basic routing: path → component
  • Catch-all routes: path="*" for 404s
  • Route ordering: Catch-all must be LAST!
  • Navigation: Use Link, not <a> tags

SPA: Single Page Application
  • Single page that changes content
  • No full page reload
  • Faster, better UX
  • URL stays in sync
