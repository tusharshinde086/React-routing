# React Routing Project

## Create Project
```bash
npm create vite@latest react-routing -- --template react-ts
```

## Go to Project Folder
```bash
cd react-routing
```

## Install Dependencies
```bash
npm install
```

## Install React Router
```bash
npm install react-router-dom
```

## Start Development Server
```bash
npm run dev
```

## Build Project
```bash
npm run build
```

## Preview Build
```bash
npm run preview
```
